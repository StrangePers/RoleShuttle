# Orders example

The operator selects the chat model in their client. If they enabled RoleShuttle, read the controller skill with `roleshuttle skill`. Use their local role profile for handoffs. A specialist can resolve a design question and a reviewer can challenge it before you edit. Ask the user in this chat when a real requirement is missing.

For the selected-orders export task, preserve the current delimiter and input order. Return a header for empty selections. Use the existing export options and check the result with `python -B checks.py export`. The patch should touch only options.json. This example stores no customer data.
